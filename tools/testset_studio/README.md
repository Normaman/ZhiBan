# 测试集工作台

本地开发工具，用于维护 Agent 行为和知识库解析两类 JSONL 测试集。Agent 行为集已合并原有 216 条基础用例和 80 条优化用例，共 296 条；知识库解析集有 28 条。它不启动客服系统，不依赖 Docker、Java 服务、PostgreSQL、Redis，也不会调用大模型。

## 启动

在项目根目录、已安装 Agent 开发依赖的 Python 环境中运行：

```bash
python -m tools.testset_studio
```

浏览器打开 `http://127.0.0.1:8765`。首次启动会将当前评测集复制到 `.runtime/testset-studio/`，之后页面只改这个独立副本。已有工作台数据会在首次升级时保留，并补入原有基础用例；相同编号以本地编辑版为准。可用参数指定其他目录或端口：

```bash
python -m tools.testset_studio --data-dir ./my-testsets --port 8765
```

## 使用

- 搜索、筛选、创建、编辑、删除测试用例；主界面按“买家问题、理想回答、可用资料”填写，程序编号等高级字段默认折叠。
- 导入 JSONL、NDJSON 或 JSON 数组，可选择覆盖或按编号合并。
- 导出当前测试集 JSONL，再通过评测命令的 `--dataset` 参数使用。
- Agent 行为集对应 `evals/agent_cases.jsonl`，是统一后的 296 条主评测集；原 `evals/agent_optimization_cases.jsonl` 保留为 80 条优化用例子集。
- 每次写入前自动保存带时间戳的备份文件。
- 知识库解析页的“运行解析评分”会执行项目当前的实际文档解析和条目分类逻辑，不调用模型。当前只自动评分解析用例；去重、替换、删除等涉及数据库生命周期的用例会标为尚未接入适配器。

默认仅监听本机回环地址，不要通过 `--host 0.0.0.0` 暴露到不可信网络。
