# Edge 订单请求检查

此临时扩展只监听 Edge 中拼多多订单列表页面已经发出的 `recentOrderList` 请求。它不会自动发请求，也不会把数据发送到知伴或其他网络地址。

扩展只在当前浏览器会话的扩展存储中保留一份摘要：HTTP 状态、平台业务码、订单数、请求筛选字段、首条记录的字段名，以及一小组非联系方式字段的截断样例。订单号只显示末四位，商品编号和图片地址只显示是否存在；不保存完整订单记录。

## 安装与使用

1. 在 Edge 打开 `edge://extensions`。
2. 开启“开发人员模式”，选择“加载解压缩的扩展”。
3. 选择本目录：`tools/edge-order-probe`。
4. 在同一个 Edge 中打开拼多多商家后台订单列表，手动点击查询。
5. 点击工具栏中的“知伴订单请求检查”图标，查看最近一次请求摘要。

结束后可在 `edge://extensions` 删除扩展。它不会读取登录 Cookie、`anti-content`、买家姓名、联系方式或订单地址。当前版本用于验证 Edge 页面的业务响应，不会把订单导入知伴。
