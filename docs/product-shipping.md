# 商品发货、预售与运费

「同步商品」同时更新列表与详情，商品详情以折叠区域显示包邮、需付运费及不配送地区。没有额外的强制刷新或分类规格同步按钮。详情格式版本 3，原版本 2 在下次同步时补读一次；完整详情六小时内复用，运费未取得或未解析的详情会在下次同步重试。

数据来自授权店铺的只读商家接口。`/glide/v2/mms/query/commit/on_shop/detail` 的商品 ID、店铺 ID 先校验，随后以返回的 `cost_template_id` 查询 `/express_inf/cost_template/get_one`，请求体 `costTemplateId`；结果 ID 必须一致。仅保留配送与计费白名单，不保留发货人地址、联系人或商家凭据。

字段含义已对照当前商家详情页脚本核验，没有根据字段名猜测：

| 平台字段 | 处理 |
| --- | --- |
| `shipment_limit_second` | 发货及揽收秒数，普通商品按小时或天展示；`delivery_one_day=1` 且 86400 秒时为当日 |
| `is_pre_sale` / `pre_sale_time` | 非预售或定时预售；时间戳为秒，按北京时间对应日期的 23:59:59 展示发货及揽收截止时间 |
| `is_group_pre_sale` | 时段预售，按支付成功后若干天计算 |
| `is_sku_pre_sale` / `is_sku_shipment` / `is_sku_group_pre_sale` | 提示按规格设置，保留各 SKU 的预售日期与发货时间列表；未定位规格不套用商品统一时效 |
| `dispatchFree.areaList[].province` | 省级包邮地区；省 ID 对照商家脚本 `mapregions`，不使用国家行政区划码猜测 |
| `dispatchCost` | 首段、续段数量与费用；`costType=0` 为件、1 为重量，重量单位克；费用及满额包邮门槛均为分 |
| `hasMinCount` / `hasMinAmount` | 保留满件或满额包邮条件；缺失条件、单位或费用不视为完整规则 |
| `nondeliveryAreas` | 不配送地区，不能混作仅需加运费的地区 |

当前解析已核验的省级模板。`regionCostTemplateConfig` 非空的高级市县模板、未知省 ID 或不完整收费字段标记 `unsupported`，界面明确显示待人工核对，不能据此承诺包邮。未列地区不推断为免费配送；没有根据价格或品名推断配送方式，也没有计算订单最终运费。计费重量、购买件数、活动和结算结果仍可能影响最终费用。

Agent 新增只读 `get_product_shipping`，使用当前咨询商品或明确商品 ID 查实时详情；地区参数仅传省级名称，不索取姓名、电话或完整地址。商品时效、预售及运费由平台事实引用，优先于全店通用发货规则。查不到时说明缺失或转人工，不能把同店其他商品的时效套用过来。页面详情继续是同步快照，旧草稿需重新生成。
